# 📊 Amazon Products Sales Analysis Dashboard

An interactive Power BI dashboard analyzing Amazon product sales, reviews, and trends. Features YTD/QTD metrics, top products, category breakdowns, and dynamic filters using Excel data.

## 📁 Project Files

- `Amazon_Combined_Data.xlsx` – Source data used for dashboard
- `Dashboard_Screenshot.png` – Visual preview of the Power BI dashboard

## 🚀 Features

- 📅 Year-to-Date (YTD) and Quarter-to-Date (QTD) sales
- 📦 Product-wise sales and units sold
- 💬 Reviews and customer engagement tracking
- 📈 Sales trends by month and week
- 🏆 Top 5 products by sales and reviews
- 🧭 Dynamic filters for product and quarter

## 🛠 Tools Used

- Power BI for dashboard development
- Microsoft Excel for data preparation
